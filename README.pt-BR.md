
# StockFlow — Sistema de Gestão de Estoque

[🇺🇸 English](README.md) | [🇧🇷 Português](README.pt-BR.md)

**Status:** Em desenvolvimento 🚧

Sistema web de gerenciamento de estoque, com foco no cadastro de produtos, controle de movimentações, acompanhamento do inventário e geração de relatórios.

## Sobre o projeto

O StockFlow é um projeto acadêmico desenvolvido para a unidade curricular de Garantia e Qualidade de Software da UNISUL (Universidade do Sul de Santa Catarina).

O objetivo é construir uma aplicação confiável e de fácil manutenção, aplicando princípios de engenharia de software, testes automatizados e integração contínua.

## Funcionalidades planejadas

- Cadastro e gerenciamento de produtos.
- Registro de entradas e saídas.
- Controle de inventário.
- Histórico de movimentações.
- Monitoramento de produtos com estoque baixo.
- Relatórios de estoque.
- Gerenciamento de funcionários.

## Regras de negócio

- A quantidade de produtos em estoque não pode ser negativa.
- Saídas não podem ultrapassar a quantidade disponível.
- Toda movimentação deve ser registrada.
- As alterações no inventário devem ser consistentes e rastreáveis.
