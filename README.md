
# StockFlow — Inventory Management System

[🇺🇸 English](README.md) | [🇧🇷 Português](README.pt-BR.md)

**Status:** In Development 🚧

A web-based inventory management system focused on product registration, stock movements, inventory tracking and reporting.

## About the Project

StockFlow is an academic software development project created for the Software Quality Assurance course at UNISUL (Universidade do Sul de Santa Catarina).

The goal is to build a reliable and maintainable application while applying software engineering principles, automated testing and continuous integration practices.

## Planned Features

- Product registration and management.
- Stock entries and exits.
- Inventory tracking.
- Stock movement history.
- Low-stock monitoring.
- Inventory reports.
- Employee management.

## Business Rules

- Stock quantities cannot become negative.
- Stock exits cannot exceed available quantities.
- Every stock movement must be recorded.
- Inventory changes must be consistent and traceable.
